# Database SQL setup

The SQL setup is split into two focused guides:

- [DATA_TABLES_README.md](DATA_TABLES_README.md): demo tables, property graph,
  seed data, and verification.
- [ORACLE_AI_DATABASE_AGENT_README.md](ORACLE_AI_DATABASE_AGENT_README.md):
  Select AI credentials/profiles and the managed Oracle AI Database Agent.

The documented deployment uses the `FINANCIAL` schema in `paulparkdb`.
Do not commit wallets, passwords, or API keys.
